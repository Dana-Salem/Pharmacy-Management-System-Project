# Pharmacy Management System

Pharmacy Management System is a C++ object-oriented programming project designed to manage pharmacies, medications, customers, and prescription/off-the-shelf medication types.

## Project Overview

The project applies core OOP concepts through a pharmacy management system. It includes multiple classes, inheritance relationships, composition.

## Main Features

- Manage medications, customers, and pharmacy information
- Add and remove medications
- Support different medication types
- Manage prescription and off-the-shelf medications
- Store customer address information


## Technologies Used

- C++
- Object-Oriented Programming
- Dynamic Memory Allocation
- Modular Class Design
